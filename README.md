# iLiFE! 全楽曲イントロクイズ 💖🎵

アイドルグループ **iLiFE!（アイライフ）** の全79楽曲（シングル・アルバム・メンバーソロ曲）を完全網羅した、Webブラウザで遊べるイントロクイズゲームです。  
Python (Flask) と SQLite データベースで構築されており、公式の原曲プレビュー音源による本格的なイントロ再生、リアルタイムのハイスコアランキング、全楽曲図鑑機能を搭載しています。

## 🌟 主な特徴
- **全79曲を網羅**: 『アイドルライフスターターパック』『初恋リバイバル』『会いにKiTE!』『サイクロンライフ！』から、最新曲『BRAVE GROOVE』、メンバーソロ曲まで完全収録！
- **本物の公式原曲オーディオ再生**: Apple Music / iTunes の公式プレビュー音源と連動し、本物の歌声とサウンドでイントロドンを楽しめます。
- **正解時のジャケット表示＆フル試聴**: 回答後に公式ジャケット写真が表示され、「🎧 原曲の続きを聴く」ボタンでサビまで試聴可能。
- **多彩な出題モード**: 10問 / 20問 / 50問（超特盛）から選択可能。
- **スピード＆コンボボーナス**: 早く正解するほどタイムボーナス獲得！連続正解でコンボ倍率アップ。
- **SQLite データベース**: 楽曲マスタ管理、ランダム4択自動生成、正解判定、TOP 10 リーダーボードをリアルタイム集計。
- **称号システム**: スコアに応じて「👑 伝説の神推しアイライファー！」「💖 ガチ恋最前列マスター！」などの称号を付与。
